How to set up:
1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click Generate new token, give it a name, select the gist scope only
3. Copy the token and paste it below — it's stored only in your browser
Push — saves your current data to GitHub (overwrites remote)
Pull — loads data from GitHub into this planner (overwrites local)
